# Control Point Survey (web app)

Phone app for numbering survey control points on site without using a number twice: RD main control points
(RD + year + number, never repeated), T temporary points and personal numbers per project. Records the approximate
position (GPS or a tap on the OneMap / project drawing map) and photos; works offline once opened; data stays on
the phone until it is exported as a zip for the office.

Open: https://jianghp0818-prog.github.io/control-point-survey/
